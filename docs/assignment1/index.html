Assignment 1.4

Is Crime Everywhere, or Just Somewhere?

Ranking all locations by incident count and plotting on log-log axes reveals whether distribution follows a power law.

Python · assignment1_figures.py 
# Count incidents per lat/lon, rank, log-log plot
loc_n  = df_geo.groupby(["latitude", "longitude"]).size()
             .sort_values(ascending=False).values
ranks  = np.arange(1, len(loc_n) + 1)
coef   = np.polyfit(np.log10(ranks), np.log10(loc_n + 1), 1)
 
fig = go.Figure()
fig.add_trace(go.Scatter(x=ranks, y=loc_n, mode="markers"))
fig.add_trace(go.Scatter(x=ranks, y=10**np.polyval(coef, np.log10(ranks)),
                         mode="lines", name=f"fit α={-coef[0]:.2f}"))
fig.update_layout(xaxis_type="log", yaxis_type="log")
fig.write_html("docs/assignment1/fig4_powerlaw.html")
Power law confirmed: The near-straight line on log-log axes shows that roughly the top 5% of locations account for the majority of all incidents.

Implication: The "average block" is a misleading statistic. Neighbourhood-level aggregation obscures extreme local concentration.
